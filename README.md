## Установка и запуск проекта

### 1. Клонирование репозитория

1. Откройте командную строку (CMD).
2. Перейдите в папку `C:\Users\Пользователь`.
3. Выполните команду:

```bash
git clone https://github.com/kubik5253-afk/VOLTRIDE.git
```

После этого проект будет загружен на компьютер.

### 2. Создание базы данных

1. Откройте MySQL Workbench.
2. Найдите файл базы данных по следующему пути:

```text
C:\Users\Пользователь\Desktop\VOLTRIDE\volt-ride\database\volt_ride_schema.sql
```

3. Откройте этот файл в MySQL Workbench.
4. Выполните SQL-скрипт, чтобы создать базу данных и необходимые таблицы.

### 3. Настройка переменных окружения

Для подключения к базе данных и работы авторизации необходимо создать файл `.env.local`.

Файл должен находиться в корневой папке проекта, рядом с `package.json`.

**Важно:** название файла должно быть именно `.env.local`, а не `env.local` или `.env.local.txt`.

Создайте файл и добавьте в него следующие переменные:

```env
DB_HOST=127.0.0.1
DB_PORT=3306
DB_USER=root
DB_PASSWORD=ВАШ_ПАРОЛЬ_MYSQL
DB_NAME=volt_ride

SESSION_SECRET=ВАШ_СЕКРЕТ_ДЛЯ_СЕССИЙ_МИНИМУМ_32_СИМВОЛА
CRON_SECRET=ВАШ_СЕКРЕТ_ДЛЯ_CRON

ADMIN_NAME=Администратор
ADMIN_EMAIL=admin@example.com
ADMIN_PASSWORD=НАДЕЖНЫЙ_ПАРОЛЬ_ОТ_12_СИМВОЛОВ
```

Замените примеры на реальные значения. Укажите пароль от MySQL, создайте секрет для сессий длиной не менее 32 символов и задайте надёжный пароль администратора длиной не менее 12 символов.

### 4. Установка зависимостей и запуск проекта

1. Откройте командную строку (CMD).
2. Перейдите в папку проекта:

```bash
cd C:\Users\Пользователь\Desktop\VOLTRIDE\volt-ride
```

3. Установите необходимые зависимости:

```bash
npm install
```

4. Создайте учётную запись администратора:

```bash
npm run seed
```

5. Запустите приложение:

```bash
npm run dev
```

### 5. Открытие приложения

Откройте браузер и перейдите по адресу:

```text
http://localhost:3000
```

После выполнения всех шагов приложение VOLT RIDE будет доступно для работы на вашем компьютере.
